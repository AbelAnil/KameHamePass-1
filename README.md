# Kamehame Pass

Kamehame Pass is a student-driven resource forum where students upload notes, peer-review content, and upvote top-quality materials.

## Features
- User authentication (signup/login)
- Post notes (text, PDF, images)
- Commenting & peer reviews
- Upvote/downvote system
- Sort/filter by subject, popularity, latest

## Tech stack
- Frontend: React + TailwindCSS
- Backend: Node.js + Express
- DB: MongoDB
- Auth: JWT
